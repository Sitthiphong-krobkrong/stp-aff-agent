# Roadmap

| Phase | Deliverable | Exit gate |
|---|---|---|
| P0 | Repository audit & access | Actual files/integrations/permissions confirmed |
| P1 | **Autonomous POC v0.1** | 3 sourced candidates → 1 licensed product → real MP4 → approval-ready package |
| P2 | Repeatable Content Factory | State machine, bounded retries, storage, provenance, batch jobs, quality controls |
| P3 | Approval Dashboard | Preview, approve/reject/regenerate, role-based control and audit logs |
| P4 | Authorized Publishing | TikTok/Shopee adapters only where permissions permit; manual upload fallback |
| P5 | Analytics & Optimization | Verified report imports, attribution boundaries, experiment feedback |
| P6 | VPS Migration | Move control plane to VPS, secure Mac native video worker and shared storage |

## Delivery principle
Never allow an infrastructure rewrite, polished dashboard or multiple-agent framework to substitute for the first real rendered clip. Quality and legal reuse rights outrank throughput.
